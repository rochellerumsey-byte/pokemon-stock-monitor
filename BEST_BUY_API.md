# Best Buy data validation and configuration

Validation date: 2026-09-27. **The Products API integration is fixture tested; no authenticated API call or Railway API call has been verified.** No API key was available in this environment. A direct no-key request to `GET https://api.bestbuy.com/v1/products/6608206.json` returned HTTP 403 with “unable to locate your API Key.” Direct unauthenticated requests to a current Best Buy search page, category page and product page timed out here. A normal browser rendered the search page, but that does not establish reliable server-side HTML access from Railway. The app therefore does not fall back to HTML when its API key is missing or the API fails.

## Recommended source

Use Best Buy's [documented Products API](https://developer.bestbuy.com/apis). The [developer documentation](https://bestbuyapis.github.io/api-documentation/) describes `GET /v1/products(...)` for filtered product search and `GET /v1/products/{sku}.json` for a known SKU. The app supports a Best Buy category URL with `id=pcmcat...` or a search URL with `st=keywords` as the configured discovery source, then makes a documented API query. It walks complete cursor pages before accepting a scan. A zero, partial, invalid or incomplete response cannot establish the silent baseline. Later unseen SKUs enter ordinary monitoring.

The API documents SKU, title, `salePrice`, `onlineAvailability`, `releaseDate`, `image`, `active`, `condition`, `preowned`, `secondaryMarket`, and product URLs. The API's `url` can be a click link that expires, so the app derives a SKU-based Best Buy link (`https://www.bestbuy.com/site/<sku>.p`) and queries by SKU. This stable link is a redirect rather than the current canonical `/product/.../<BSIN>` URL. It was observed to redirect to the correct current product page for SKU 6608206; other SKUs require live validation. A modern `/product/.../<alphanumeric BSIN>` URL does not expose the numeric SKU and stays `UNKNOWN` unless a SKU URL is provided.

`onlineAvailability=true` supports online in-stock monitoring; `false` supports out-of-stock monitoring. A future `releaseDate` is shown as `COMING_SOON`, never assumed to be a preorder. The API documentation does not define a reliable preorder flag or seller identity. Seller stays unknown, so Best Buy products cannot match purchase rules. Missing/ambiguous price, identity or availability also stays non-purchasable. The API price restriction field blocks use of an undisclosed price. Images are accepted only from HTTPS Best Buy static-image hosts.

## Key, limits and next validation

1. Register for a Products API key using [Get API Key](https://developer.bestbuy.com/) and the email activation described in the [getting-started documentation](https://bestbuyapis.github.io/api-documentation/). Best Buy advertises self-service signup, but issuance to this particular small project has not been tested. Commerce API access is separate and invite-only; this app does not use it.
2. Review the [API terms](https://developer.bestbuy.com/legal), especially use of product content, links and the 72-hour cache limit. The worker expires Best Buy API-derived title, price, status, release and image content after 71 hours without refresh while retaining SKU identity for monitoring and deduplication. Confirm with Best Buy if long-term SKU identity retention for this use is permitted before enabling production use.
3. Set `BEST_BUY_API_KEY` in Railway Variables on the app service. Do not put it in GitHub Actions, source files or a discovery URL. Restart the service. The key is sent only as the documented `apiKey` query parameter to `api.bestbuy.com`; application errors do not log request URLs or the key.
4. Add a source such as `https://www.bestbuy.com/site/pokemon/pokemon-trading-cards/pcmcat1741200145801.c?id=pcmcat1741200145801` or `https://www.bestbuy.com/site/searchpage.jsp?id=pcat17071&st=pokemon+tcg`. Confirm the first complete nonempty scan becomes a **silent baseline**. Check the API's actual search coverage and whether the category ID is accepted before relying on discovery.
5. Add a known numeric-SKU product URL such as `https://www.bestbuy.com/site/6608206.p`, then verify price and online availability in Railway against Best Buy's site. Observe an actual stock transition before calling restock alerts live verified. Confirm future-release handling on a real upcoming item. Seller remains unknown; do not enable purchasing based on this feed.

The [published limits](https://developer.bestbuy.com/legal) are 50,000 calls/day and 5 calls/second per key for these APIs; a 403 can also mean the quota was exceeded. The worker spaces serial API calls by 250 ms. Multiple service instances share the same key quota, so the single advisory-locked worker is important. Approval traffic could add calls. No production call rate has been measured.
