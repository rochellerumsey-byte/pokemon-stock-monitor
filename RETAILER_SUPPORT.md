## Phase 2 discovery validation

Target HTML discovery and Best Buy Products API discovery are **FIXTURE TESTED ONLY**. Safari Zone collection discovery and known-product monitoring have both fixture tests and live local observations; the silent baseline and new-product transition are fixture tested but have not yet occurred on Railway. No live Best Buy API response from Railway has been verified. Pokémon Center, GameStop, Amazon, and generic retailers have **no discovery adapter**. Zinc sandbox order tests are mocked; no real Zinc sandbox submission or Discord delivery has been confirmed.

An ordinary HTTP request to the [Pokémon Center TCG catalog](https://www.pokemoncenter.com/category/tcg-cards?page=1) returned a `Pardon Our Interruption` challenge page with zero product links on 2026-09-28. An ordinary [GameStop search](https://www.gamestop.com/search/?q=pokemon%20tcg) returned HTTP 403. Neither was bypassed. Game Nerdz product pages expose structured offers, but its Pokémon category did not render product cards in ordinary HTML, so Safari Zone's explicitly published read-only collection feed was selected instead.

The Target regression fixtures also model the current public category shell and product loading placeholders. Those tests verify that the app refuses an empty baseline and reports `UNKNOWN` for unconfirmed product data; they do **not** demonstrate working live discovery. The older `/c/pokemon-cards` sample URL now returns HTTP 404. Target describes its Redsky catalog APIs as client-managed services for its web and app teams in its [engineering article](https://tech.target.com/blog/empowering-clients-api). We have no documented public catalog/availability feed usable from Railway. Target discovery should remain paused until Target supplies an authorized data source or a different supported architecture is selected.

The discovery adapter registry supports retailer-specific URL identities and card selectors. Both documented Best Buy `/product/.../<sku>` and `/site/.../<sku>.p` URL shapes are covered by local tests; this does not verify current Best Buy pages. Ambiguous prices and multiple structured offers remain unconfirmed, which blocks AUTO rules. Seller identity from a single structured offer is retained for rule evaluation. Retailer-direct fulfillment at Zinc checkout has not been independently verified and must be validated before any future live purchasing phase.
